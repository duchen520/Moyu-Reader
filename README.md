# 墨屿 v0.5.18

墨屿，原 Tomato Reader。翻开一页，暂别喧嚣。

## v0.5.18 自定义标题栏与新名称

- 主窗口更换为随白天、夜间和护眼主题变化的标题栏，保留拖动、双击最大化/还原，以及最小化、最大化、关闭按钮。启动和错误页面也保留窗口控制。
- 窗口、侧栏、阅读页标识、安装器和图标统一为“墨屿”。应用资料标识、数据库名、存储键及 GitHub 更新仓库沿用原值，避免更名后换成一份空白书架。
- Windows 安装包只在升级到同一个安装目录时移除旧名称的卸载注册，不清理个人资料，不删除独立安装在其他位置的旧版。
- 原始图标矢量位于 src-tauri/icons/moyu.svg；scripts/render-brand-icons.py 可使用 Pillow 重建随源码附带的 PNG/ICO。
- 详细验证见 TEST_REPORT-0.5.18.md。此次没有新增自动备份或数据库修复功能。

## v0.5.17 代码审查修复

修复 EPUB 重复段落被删除、嵌套正文重复、路径解析及损坏文件部分导入；为解压正文设置容量限制。
修复三种音频播放在取消/切章后仍可能接上旧音频，以及系统媒体键的集数导航与重复暂停/播放。
Kokoro 卸载在语音线程释放模型后清理文件，串行处理导入/卸载并报告实际失败；补齐新命令权限，修正中文目录选择输出编码和模型下载版本。
更新检查按语义版本处理预发布/构建号，超时覆盖响应体读取并优先选择安装程序。长目录在实际行高渲染后校正当前章节居中位置。

本次交付为 **源码修复版**。Linux 下的前端构建、浏览器模拟回归和不含桌面特性的 Rust 测试见 TEST_REPORT-0.5.17.md。
尚未在 Windows 构建或实机验证 EXE、WebView2、中文目录选择和模型文件锁释放。旧 EXE 不包含这些修复，不能仅覆盖源码或 dist 就当成程序已更新。

在 Windows x64 Visual Studio 开发者 PowerShell 中运行 ./BUILD-WINDOWS.ps1 构建新版。依赖和详细步骤见本文后面的开发构建说明。
新增定向回归：npx playwright install chromium 后运行 npm run test:audit。

GitHub Actions 的 Windows 工作流已补齐 Python/MSVC 环境和固定 Kokoro 引擎编译，成功后提供 NSIS 安装包及携带 resources 的便携ZIP。工作流可手动触发，也会在本次修复分支推送或PR时运行；实际构建状态以 Actions 为准，此处不声称已生成Windows程序。

## v0.5.15 内置 Kokoro 离线语音

- 听书面板新增“Kokoro 离线语音”，支持本地书和已正常加载的官方正文，提供55个中文女声、45个中文男声音色。
- 引擎直接运行在阅读器进程内，固定使用CPU/2个推理线程，不运行Python、GPU服务或本地HTTP端口。点击朗读才加载模型，暂停/停止会取消会话并在当前短段处理退出后卸载；30秒无任务也会卸载。
- 支持从可见段落开始、暂停续播、播放倍速、下一章连续朗读、收起后的迷你控制和共用定时停止；与电脑语音、番茄AI、官方有声互斥。切换音色会停止原朗读，手动切章/离开阅读器会取消旧音频。
- 语音包首次在面板粘贴解压目录并导入。只接受固定Kokoro 1.1中文INT8版本，逐个校验375份所需文件，校验完成后发布到应用本地资料目录；不修改原下载目录。导入后可移走原下载文件夹。
- 安装包仅含原生引擎，不捆绑语音模型。便携版需要完整ZIP中的EXE及resources目录，不能只复制EXE。
- 语音模型独立于阅读资料，阅读数据库、云端上传开关和账号流程未变。验证和实际限制见 TEST_REPORT-0.5.15.md。

开发构建新增前置步骤：在x64 Visual Studio开发者终端内，用Python 3.12+运行 `python scripts/prepare-kokoro-engine.py`，下载校验固定CPU SDK并编译桥接DLL，再执行原Tauri构建。`BUILD-WINDOWS.ps1`已包含这一步。干净源码包不包含DLL、模型或测试资料。

## v0.5.10 大TXT导入与手动切章续滚

- 取消本地UTF-8 TXT导入的1.5MB硬上限，仍校验TXT格式、空文件及乱码。实测26,257,293字节（约25MiB）测试文件自动分为1200章，保存并重开可正常阅读；实际可处理规模仍受磁盘、WebView配额和内存限制。
- 小说书架及正文改存IndexedDB，每本书独立记录，不再将整套书架全文反复序列化进localStorage。进度、偏好与账号资料的位置和已有键保持原样。
- 首次启动将旧书架与迁移标记在同一事务中保存，保留原始旧书架快照；事务成功且读取成功后才移除旧键。迁移失败保留旧副本并提供重试，不显示误导的空书架。残留旧副本不会在下次启动覆盖新资料或恢复已删除的书。
- 收藏、导入和删除等待数据库事务完成后才更新界面，串行处理并发写入。保存失败明确提示，未保存的书不加入书架。
- 修复手动下一章、上一章、目录切章、Ctrl+方向键及页末快捷键切章时关闭自动阅读的问题，保留模式、速度和翻页间隔；切章仍停止旧音频及取消旧播放请求。主动停止、返回书架及定时停止保持原行为。
- 测试和边界见TEST_REPORT-0.5.10.md；大文件/迁移回归：npm run test:large-txt。

## v0.5.9 按住暂缓、目录收展与多色主题

- 云端上传提示换为蓝色，关闭状态使用紫色标记；目录、云端、账号、听书控件加入蓝/紫/玫瑰色点缀，橙色保留给主要操作。白色、羊皮纸、深色主题分别适配。
- 验证见 TEST_REPORT-0.5.9.md；新操作回归可运行 npm run test:reading-controls。

## v0.5.8 听书抽屉与播放控制修复

- 合入Gemini的顶部听书抽屉和四个分页：电脑语音、番茄AI音色、官方有声、自动阅读。首次选择后保留播放器，收起抽屉继续播放；选择前不预加载听书目录。
- 修复AI与真人播放器同时常驻后的播放冲突，包括下载中的旧请求；迷你播放器支持暂停、继续、停止和取消加载，暂停后不会消失。统一定时停止入口适用于全部播放模式。

- AI段落位置按音频时间与文字字数估算，不是官方精确逐段时间。改为明确标注且默认关闭的“按估算位置跟随正文”，不强行改变阅读位置；高亮不再改变段落排版宽度。
- 修复浅色主题新控件的小字对比度，限制抽屉高度以保留正文空间，并检查900像素窗口下的迷你控制。
- 同步应用、界面与两份依赖锁定文件版本为0.5.8；保留原阅读数据键和云端上传开关。验证见 TEST_REPORT-0.5.8.md。

## v0.5.7 有声章节定位与段评

- 阅读器 → 耳机 → 查看番茄官方有声版 → 从当前文字章节播放：使用官方对应关系选择集数并跳到章首秒数；没有对应数据时明确提示，仍可手动选集。
- 已实测《网游：我有超神级天赋》文字第887章对应有声第729集的3分47.17秒，避免把文字章节号直接当集数。
- 正文段落旁显示官方评论数量，点击可查看该段评论、继续加载和查看回复；阅读设置或工具栏可关闭段评气泡。保留原始段落编号，旧缓存正文不一致时不强行对应。
- 评论按需读取；切章、切版本时丢弃过期结果。查看评论与听书定位不上传阅读进度，听书秒数仍存本机。当前支持查看，不包含发布评论、点赞。
- 段评协议参考 [ch6vip/fqapp](https://github.com/ch6vip/fqapp)，请求、校验、解析与界面由本项目实现。验证见 TEST_REPORT-0.5.7.md。

## v0.5.6 番茄AI朗读音色

## v0.4.3 进度保护与恢复

自动上传已关闭。切章、打开作品、切回窗口和读取云端记录都不会写入云端进度。读取与上传分为独立按钮；只有查看当前云端章节与将上传的章节并再次确认后，才会尝试上传。确认后若云端记录又发生变化，会停止本次上传。

新增“查看已读章节”，可按章节编号或标题搜索，并只在电脑打开选中章节。已读集合不代表最后停留位置，不自动采用其中编号最大的章节，也不自动上传恢复位置。

后端按更新时间选择同一本书的最新记录，兼容秒/毫秒时间戳；最新记录存在冲突时停止猜测。真实账号已验证只读历史接口，未用真实账号测试上传与手机接收结果。

## 安装和使用

运行 `Tomato-Reader-0.5.6-x64-setup.exe`，支持Windows 10/11 x64。已有版本可覆盖安装，保留原应用标识和本机记录。缺少WebView2时安装器会联网补齐；本包没有Windows发布者代码签名。

在“账号管理”登录，“云端书架”查看藏书；在“找书发现”搜索书名/作者，或粘贴番茄作品链接、书籍ID。打开作品后逐章读取正文，不要求导入TXT。原有字体/主题、目录、阅读位置、自动滚动/翻页、电脑朗读和定时停止保留。

## v0.4.1 书架修正

用户已在Windows确认v0.4.0可登录，并可通过手动刷新读取个人书架。本版改为登录/恢复登录后自动加载书架，显示官方封面与接口返回的云端章节标题；搜索结果和已打开的正版作品也使用官方封面。图片未返回、过期或加载失败时明确显示占位提示。

书架和章节请求的失败分别显示；刷新失败保留已显示条目。若官方未返回某本书的章节记录，暂停自动上传；只有手动点击“同步本章进度”才以本机当前章节尝试建立记录。已返回的云端章节仍按目录定位，本机与云端不同时由读者选择。章内位置与听书位置仍仅在本机保存。

手机/电脑双向进度尚未在用户账号验证；不能根据书架能显示或模拟测试通过就认定手机进度已同步。v0.4.1模拟界面回归见 TEST_REPORT-0.4.1.md，v0.4.0后端真实正文/音频证据保留。

## 本版新增

- 正文使用正常设备会话、本地签名及官方App接口；Windows凭据管理器保存设备标识，会话密钥只在后端内存。实际付费、验证或不完整正文会报错停止，不激活会员、不改变购买状态、不轮换设备。
- 书评按真实游标分页；一级回复支持继续加载。内容和统计只展示官方实际返回的数据，章评、段评及二级回复完整分页未接入。
- 真人有声由后端取得官方媒体并处理，界面通过本机Blob交给播放器。支持播放/暂停、拖动、倍速、上下集、自动连播、定时停止及本机听书位置恢复；电脑朗读与有声互斥。
- 音频采用整集加载，上限32MB，首次需等待加载。支持已实现的单音轨MP4 CENC布局；实际AAC/Opus/FLAC解码能力取决于WebView2。未知格式会明确报错。
- 没有第三方正文、远程签名或音频解析服务器。

## 请求和凭据

官方请求按主机至少间隔500毫秒。429/503触发60、120、240、480、900秒退避，并遵循更长的Retry-After；不自动重放请求。冷却状态持续到本次程序退出。

网页登录和App设备标识分别由Windows凭据管理器保存。远程网页窗口不能调用本机原生命令；正文/媒体密钥与媒体地址不进入阅读记录或源码包。音频Blob在切换和退出时回收。
